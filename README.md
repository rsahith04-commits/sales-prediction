# 📈 SalesPilot – E-Commerce Sales Prediction System

**SalesPilot** is a web-based E-Commerce Sales Prediction System developed to help businesses manage products, track sales, analyze revenue, and estimate future product demand.

## 🚀 Features

- 🔐 **Admin Login** – Login page with demo credentials.
- 📊 **Dashboard** – Displays total revenue, units sold, products, and transactions.
- 📦 **Product Management** – Add, view, and delete products.
- 💰 **Sales Management** – Record sales and automatically update product stock.
- 📈 **Revenue Analytics** – Visualize product-wise revenue using charts.
- 🤖 **Sales Prediction** – Estimate future sales for 7 or 30 days using historical sales data.
- 📋 **Sales History** – View and search previous transactions.
- 💾 **Data Storage** – Saves product and sales information using browser LocalStorage.
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- HTML Canvas for charts

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in Google Chrome or Microsoft Edge.
4. Enter the demo login credentials.
5. Start managing products and recording sales.

## 🔮 Sales Prediction Method

The system uses historical sales records from the last 30 days to calculate average daily sales and estimate demand for the next 7 or 30 days.

## 🎯 Project Objective

The main objective of SalesPilot is to simplify e-commerce sales management and demonstrate how historical sales data can help estimate future product demand and support business decisions.
